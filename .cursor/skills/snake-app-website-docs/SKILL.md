# Snake App Website Docs Skill

Use when changing the marketing site or its documentation.

- Docs: `docs/README.md`, `ABOUT.md`, `ARCHITECTURE.md`, `FLOW.md`, `DESIGN.md`

## Checklist
1. Read `docs/README.md` and the doc that matches the change.
2. Edit HTML/CSS/assets as needed.
3. Update the matching `docs/*.md` file(s) in the **same** change.
4. Verify relative links between docs still resolve.
5. If level count, modes, platforms, offline/profile, or store status change, update `docs/ABOUT.md` (and landing copy if claims appear there).
