# About Snake App

**Snake App** is an offline-first snake game by **Chingalo Family**. Grow, collect tiered foods and animals, climb levels, and chase local high scores — without requiring a cloud account for core play.

This marketing site promotes the product and hosts the public privacy policy. The game itself ships as a Flutter app (package `chingalo.family.snake_app`).
