# Snake App Website

Marketing site for **Snake App** (Chingalo Family).

## Local Development

```bash
git clone https://github.com/chingalo-family/snake-app-website
cd snake-app-website
```

```bash
for setup development server

# Using Python
python -m http.server 8000

# Using Node.js
npx http-server

# Or simply open the file
open index.html

```

Open [http://localhost:5173](http://localhost:5173).

## Pages

| File | Purpose |
|------|---------|
| `index.html` | Landing — hero, gameplay screenshots, features, contact |
| `privacy.html` | Privacy Policy |
